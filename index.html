Kebijakan Privasi

AngkotKita — Sistem Pemesanan Angkutan Kota Sidoarjo

Terakhir diperbarui: 9 Oktober 2026

Aplikasi AngkotKita ("Aplikasi", "kami") adalah sistem pemesanan angkutan kota (Lyn Kuning) di Sidoarjo yang dikembangkan oleh Reza Mandala Putra. Kami berkomitmen melindungi privasi dan keamanan data pengguna.

Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi pribadi Anda saat menggunakan Aplikasi kami.

1. Data yang Kami Kumpulkan

a. Informasi Akun

  • Nama lengkap
  • Alamat email
  • Nomor telepon
  • Kata sandi (disimpan dalam bentuk terenkripsi melalui Firebase Authentication)

b. Data Lokasi (GPS)

Izin yang diperlukan: ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION, ACCESS_BACKGROUND_LOCATION
  • Posisi GPS pengguna saat membuka halaman peta
  • Posisi GPS sopir secara realtime saat beroperasi
  • Data lokasi digunakan HANYA saat fitur pelacakan aktif
  • Data lokasi sopir dihentikan saat sopir menekan "Selesai Narik"
⚠️ Pengungkapan Lokasi di Latar Belakang (Background Location):

Aplikasi ini mengumpulkan data lokasi di latar belakang (background) — yaitu saat aplikasi ditutup, tidak digunakan, atau layar HP mati — HANYA ketika sopir mengaktifkan fitur "Mulai Narik".

Tujuan: Data lokasi background digunakan untuk menampilkan posisi angkot secara realtime kepada penumpang di peta, sehingga penumpang dapat melihat posisi angkot yang sedang beroperasi meskipun layar HP sopir dalam keadaan mati atau sopir membuka aplikasi lain.

Penghentian: Pengumpulan lokasi background dihentikan secara otomatis saat sopir menekan "Selesai Narik". Data lokasi TIDAK dikumpulkan saat sopir tidak sedang beroperasi.

Pengiriman Data: Data lokasi dikirim ke server Firebase (Google Cloud Platform) melalui koneksi HTTPS terenkripsi. Data lokasi TIDAK dijual, diperdagangkan, atau dibagikan kepada pihak ketiga selain Firebase/Google sebagai penyedia infrastruktur. Data lokasi TIDAK digunakan untuk keperluan iklan.

c. Data Kamera

Izin yang diperlukan: CAMERA
  • Foto wajah sopir diambil saat verifikasi sebelum mulai narik
  • Aplikasi hanya mendeteksi adanya wajah yang menghadap kamera (face detection) menggunakan Google ML Kit di perangkat
  • Aplikasi tidak melakukan pengenalan wajah (face recognition) dan tidak membuat data biometrik
  • Kamera hanya aktif saat proses verifikasi wajah
  • Foto verifikasi disimpan secara terenkripsi di Cloudinary

d. Data Notifikasi

Izin yang diperlukan: POST_NOTIFICATIONS
  • Token notifikasi push (Firebase Cloud Messaging)
  • Digunakan untuk mengirim pemberitahuan status pesanan

e. Data Penggunaan

  • Log aktivitas dalam aplikasi (login, pesanan, penilaian)
  • Riwayat perjalanan dan pesanan

2. Cara Kami Menggunakan Data

Data Anda digunakan untuk:

Tujuan Penjelasan
Layanan Peta Menampilkan posisi angkot secara realtime dan menghitung estimasi jarak serta waktu kedatangan
Pelacakan Background Memungkinkan posisi angkot tetap terlihat oleh penumpang saat layar HP sopir mati atau aplikasi di latar belakang
Keamanan Memastikan sopir menunjukkan wajah ke kamera (deteksi wajah) sebelum beroperasi
Notifikasi Mengirimkan pemberitahuan status pesanan, kedatangan angkot, dan informasi penting
Autentikasi Mengelola akun pengguna dan proses masuk/daftar
Peningkatan Layanan Menganalisis penggunaan untuk meningkatkan kualitas aplikasi

3. Wilayah Layanan

Aplikasi AngkotKita beroperasi khusus di wilayah Kabupaten Sidoarjo, Jawa Timur, mengikuti rute angkot Lyn Kuning:

Rute Angkot Lyn Kuning Sidoarjo:
Pasar Tulangan → Ramayana Sidoarjo (dan sebaliknya)
  • Saat penumpang memesan angkot, aplikasi membandingkan posisi GPS penumpang dengan titik-titik rute angkot
  • Jika posisi penumpang berada di luar rute, aplikasi menampilkan peringatan bahwa wilayah tidak terdeteksi di rute angkot Sidoarjo
  • Penumpang tetap dapat melanjutkan pemesanan
  • Pengecekan wilayah dilakukan di perangkat; hasil pengecekan tidak disimpan ke server

4. Penyimpanan dan Keamanan Data

  • Data disimpan di server Firebase (Google Cloud Platform) dengan standar keamanan industri
  • Kata sandi dienkripsi menggunakan Firebase Authentication
  • Data lokasi hanya disimpan selama sesi aktif dan dihapus setelah sesi berakhir
  • Foto verifikasi wajah disimpan secara terenkripsi di Cloudinary
  • Komunikasi antara aplikasi dan server menggunakan HTTPS (Transport Layer Security)

5. Berbagi Data dengan Pihak Ketiga

Kami TIDAK menjual, memperdagangkan, atau menyewakan data pribadi Anda kepada pihak ketiga.

Data Anda mungkin dibagikan dengan penyedia layanan berikut sebatas yang diperlukan untuk operasional aplikasi:

Pihak Ketiga Data yang Dibagikan Tujuan
Firebase / Google Cloud Platform Data lokasi, data akun, token notifikasi Infrastruktur backend (autentikasi, database Firestore, notifikasi push via Firebase Cloud Messaging)
Cloudinary Foto verifikasi wajah (terenkripsi) Penyimpanan foto verifikasi wajah sopir secara terenkripsi
Penegak Hukum Sesuai permintaan resmi Jika diwajibkan oleh hukum atau perintah pengadilan yang berlaku di Indonesia
Penting: Data lokasi TIDAK digunakan untuk iklan, profiling, atau tujuan komersial lainnya. Data TIDAK dibagikan kepada jaringan iklan, broker data, atau pihak ketiga lainnya.

6. Hak Pengguna

Anda memiliki hak untuk:

  • Mengakses data: Melihat data pribadi yang kami simpan tentang Anda
  • Mengoreksi data: Memperbarui informasi akun Anda
  • Menghapus data: Meminta penghapusan akun dan seluruh data terkait dengan menghubungi kami melalui email
  • Mencabut izin: Menonaktifkan izin lokasi, kamera, atau notifikasi melalui Pengaturan Android > Aplikasi > AngkotKita
  • Menarik persetujuan: Anda dapat menarik persetujuan penggunaan data kapan saja

7. Retensi Data

  • Data akun disimpan selama akun aktif
  • Data lokasi sopir dihapus secara otomatis setelah sesi operasional berakhir (sopir menekan "Selesai Narik")
  • Riwayat pesanan disimpan untuk referensi pengguna
  • Setelah permintaan penghapusan akun, semua data pribadi dihapus dalam waktu 30 hari kerja
  • Data yang diperlukan untuk keperluan hukum dapat disimpan lebih lama sesuai ketentuan peraturan perundang-undangan yang berlaku

8. Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun. Kami tidak secara sengaja mengumpulkan data dari anak-anak. Jika kami mengetahui bahwa kami telah mengumpulkan data dari anak di bawah 13 tahun, kami akan menghapus data tersebut sesegera mungkin.

9. Perubahan Kebijakan

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diumumkan melalui aplikasi dan halaman ini. Penggunaan berkelanjutan setelah perubahan berarti Anda menyetujui kebijakan yang diperbarui.
